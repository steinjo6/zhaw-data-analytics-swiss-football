# zhaw-data-analytics-swiss-football
Data Analytics project (ZHAW) on Swiss football economics, academy talent, and regional economic power across Super League and Challenge League.

## Team-Workflow & Zusammenarbeit

Damit Code, Datenbank und Benotungs-Dokumentation am Schluss nahtlos zusammenpassen, halten wir uns an folgende 5 Regeln:

1. **Zuerst [ROADMAP.md](./ROADMAP.md) prüfen:**  
   Alle Aufgaben, Dateipfade, Funktionsvorgaben und Bewertungskriterien (gemäss [TASK_DESCRIPTION.md](./TASK_DESCRIPTION.md)) stehen Schritt für Schritt in [ROADMAP.md](./ROADMAP.md). Wenn du mit einem AI-Agent arbeitest, gib ihm immer [ROADMAP.md](./ROADMAP.md) als Kontext mit.
2. **Auf eigenem Branch arbeiten:**  
   Arbeite auf deinem persönlichen Branch (`dev-<kuerzel>`), committe **niemals** `.env` oder grosse Rohdaten/Caches (`data/raw/`) und merge erst nach kurzem Test per Pull Request in `main`.
3. **AI-Einsatz sofort in [docs/AI_USAGE.md](./docs/AI_USAGE.md) eintragen (Pflicht für Note!):**  
   Dokumentiere nach jedem Arbeitspaket in **1–2 Stichpunkten** in [docs/AI_USAGE.md](./docs/AI_USAGE.md): verwendetes AI-Tool/Modell, erledigte Aufgabe, was gut lief und **was nicht funktioniert hat / manuell korrigiert werden musste**.
4. **Status aktuell halten:**  
   Nach Abschluss und Test eines Tasks die entsprechende Checkbox (`[x]`) und Status-Zeile direkt in [ROADMAP.md](./ROADMAP.md) abhaken.
